# Fonts

The page self-hosts three typefaces so it makes no requests to font services.
All three are licensed under the SIL Open Font License 1.1; each license file
sits next to the font it covers.

| File | Family | Use | License |
|---|---|---|---|
| `young-serif.woff2` | Young Serif | Names and headings | [`OFL-YoungSerif.txt`](OFL-YoungSerif.txt) |
| `figtree.woff2` | Figtree (variable, 400–700) | Interface text | [`OFL-Figtree.txt`](OFL-Figtree.txt) |
| `barlow-condensed-600.woff2` | Barlow Condensed SemiBold | Stamped dates and numbers | [`OFL-BarlowCondensed.txt`](OFL-BarlowCondensed.txt) |

The files are the Latin subsets served by Google Fonts, unmodified.
